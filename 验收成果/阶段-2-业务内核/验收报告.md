# 阶段二验收报告

## 阶段范围

仅实现《JudgeFlow-开发顺序.md》的“阶段 2：数据库、状态和法律执行”。本阶段未启动或实现 FastAPI、HTTP API、MCP、Skill、Agent、AgentTeams、Matrix、前端、Docker、RAG、消息队列或额外数据库。

## 完成内容

- 定义 SQLAlchemy 2.x PostgreSQL 模型，业务表严格为 `cases`、`appeals`、`policy_evolutions`、`work_orders`、`artifacts`、`policies`、`replay_runs`、`domain_events` 八张；
- 增加单一 Alembic 初始迁移，使用 PostgreSQL `timestamptz`、`jsonb` 和受限枚举；
- 实现 Case、Appeal、PolicyEvolution 固定状态流，拒绝错误 `from_state`、非法跳转和额外循环；
- 公共状态推进仅允许三个启动边；其余状态只能在对应 Artifact 通过统一验收后推进，Human 审批边只能由绑定审批 WorkOrder 的 Artifact 触发；
- 实现 WorkOrder 创建、开始、失败和重试；失败不推进聚合状态，重试要求新 `run_id`；
- Artifact 提交先通过阶段一 `ArtifactEnvelope` Pydantic Schema，并校验 WorkOrder、执行者、运行、Trace、聚合和期望类型；
- Artifact 以 `work_order_id + run_id + artifact_type` 幂等；同键同 payload/hash 返回原 Artifact，同键异内容返回冲突；
- Artifact、Policy、ReplayRun、DomainEvent 采用只追加 ORM 语义；案件 Policy Snapshot、申诉原案快照和证据白名单不可修改；
- 风险意见和反证意见均验收成功后，Case 才能进入 `ADJUDICATING`；
- Policy 修改只插入新的 `CANDIDATE` 版本，Case 始终保留创建时锁定的 Snapshot；
- Policy 内容、Policy Snapshot、Artifact payload 与回放 dataset manifest 均由固定 Python 重新计算 SHA-256 后验真；
- 用固定 Python 实现 `EQ`、`IN`、`GTE`、`LTE`、`all_of`、`any_of`，未知运算符由权威 Pydantic Schema 拒绝，不使用 `eval`、`exec`、模板或动态函数；
- 对阶段一 TRIGGER、DRAFTING、SCORING 三个固定样本执行新旧规则比较；逐案结果覆盖三个 split，FP、FN、变化数和推荐只以 `SCORING` 计分并由 Python 计算；
- Human Approval 使用既有 `REPLAY` step 的最小约定，必须绑定 `expected_artifact_type=HUMAN_APPROVAL`、唯一 Human 执行者和新运行编号；保存为不可变 Artifact，`APPROVE` 后候选规则仍为 `CANDIDATE`，不发布生产规则。

```bash
PYTHONDONTWRITEBYTECODE=1 \
```

结果：`90 passed`。

测试覆盖既有 70 项阶段一 Schema/导出测试，以及真正实例化 `JudgeFlowKernel`/`Session` 的阶段二测试：完整主链路、三状态流门禁、失败不推进、重试新 run/Artifact、Schema/执行者/类型/producer 校验、幂等冲突、不可变与 bulk 修改拒绝、Case Snapshot 锁定、四类哈希验真、有限 DSL、只按 SCORING 计分的确定性回放、Human WorkOrder 审批以及不发布生产规则。


## 独立验收结论

独立验收 Agent 只读复验并独立运行测试，结果为 `90 passed`，结论为 `PASS`，建议批准阶段二。首次验收发现的测试覆盖不足、Snapshot 可被 bulk 修改、状态可绕过 Artifact、哈希未验真、回放评分 split 错误、Human Approval WorkOrder 类型不匹配以及 PostgreSQL 在线迁移未验证，均已在返修后复验关闭。

独立验收同时确认：Alembic revision 为 `0001_stage2`；现库只有 `alembic_version` 和规定的八张业务表；未发现 FastAPI、MCP、Skill、Agent、AgentTeams、Matrix、前端或 Docker 等阶段三及范围外实现。
